# 【重磅】排队太苦了？专家号哪里抢？试试自助机！

> 更新时间：2026-09-16 (UTC+8)

**新华医院自助机妙用**

**操作简便****：**仅需几分钟，即可轻松挂号，付费，告别排队长龙。

**号源充足****：**专家号源在各预约渠道同步更新，谁操作快，谁就能抢到！

**我能用自助机吗？**

如果您带了就诊卡+身份证，就能用。

（就诊卡指医保卡或自费卡。新华医院实行就诊实名制，一定要带好本人身份证哦~）

如果您有微信支付、支付宝支付，或者带了银行卡，用自助机就更快！

**这些就诊卡都可以使用哟**

**自助机如何使用？**

**自助挂号**

1. 点击“自助挂号”，磁条卡直接刷卡，芯片卡插入IC卡槽后点击相应图标

2. 点击“自助挂号”

3. 选择科室后确认

4. 费用确认后，完成自助挂号付费

5. 选择付费方式并完成付费

**自助预约**1
1. 点击“自助预约”，磁条卡直接刷卡，芯片卡插入IC卡槽后点击相应图标

2. 点击“自助预约”

3. 选择科室按提示完成预约

4. 点击“查询取消“

5. 可查询或取消预约

**我不会用，怎么办？**

请寻找穿着“黄马夹”的志愿者，他们很乐意为您提供帮助

部分情况自助机暂不支持哦！

目前，大部分科室就诊支持自助预约、挂号、收费等服务。

1.医保卡初诊患者（第一次持医保卡来新华医院看病）暂不能使用自助服务；

2.急诊、大病医保、产科等部分科室、诊别因特殊需求暂不支持部分自助服务，具体情况请现场咨询志愿者或工作人员。
